## 1. 产品目标与「商用成熟」验收定义
### 1.1 目标
- **G1 专业外观**：从「演示页」变为工具界面——高信息密度、可调节的三栏工作区、常驻状态栏，视觉对标 draw.io / ImHex。
- **G2 可预测的编辑控制**：每一步图编辑都能被撤销，每个操作都能在快捷键或右键菜单里找到，每个失败都能在发生位置被解释。
- **G3 规模可用且配置不丢**：200 节点量级仍可交互；pack 与图在刷新、重开浏览器后原样恢复。

### 1.2 六条可验收定义（QA 据此建基准用例）
| 编号 | 定义 | 度量方法 |
| --- | --- | --- |
| M1 帧率 | 200 节点 / 2000 端口基准图，平移与缩放平均 ≥ 45fps，p95 帧耗时 ≤ 33ms；拖动节点 ≥ 50fps | DevTools Performance 录制 10s 连续平移+缩放，取平均帧与 p95 |
| M2 启动与求值 | 打开 200 节点 / 5MB buffer 图到可交互 ≤ 1.5s；单次全图求值 ≤ 300ms | `performance.now()` 埋点 + 状态栏 `ms` 字段 |
| M3 可回退 | P0 中「图文档类」编辑操作 100% 可撤销；连续 20 步撤销后文档 JSON 与操作前深度相等，20 步重做后与操作后相等 | 脚本比对序列化后的 `{nodes,edges,packs}` |
| M4 可发现与可解释 | 全部菜单项与主操作 100% 键盘可达（有快捷键或被右键菜单收录）；被拒绝的连线/删除/导入 100% 在目标位置 3s 内提示；全体 error 级问题 100% 可点击定位到节点并居中高亮 | 逐条走查清单 + 人工点击 |
| M5 可持久 | pack、图、三栏宽度与折叠状态刷新后一致率 100%；`localStorage` 不可用时 100% 出现降级提示，无静默丢失 | F5 / 重开浏览器 / 隐私模式各 3 次 |
| M6 文案 | 禁用词扫描 0 命中；界面常驻说明句（> 40 字）0 处；术语表以外的同义叫法 0 处 | `grep` 脚本扫 `src/bp/*` + 人工通读 |

## 4. 交互规范
### 4.1 三栏布局
| 项 | 规则 |
| --- | --- |
| 栅格 | `左 | 画布 | 右`，画布 `minmax(0,1fr)` 必须可缩到 0 不撑破 |
| 宽度范围 | 左 240–480（默认 330）；右 320–640（默认 404）；记忆在持久化中 |
| 最小宽 | 左 < 240 时触发折叠而非继续压缩；右 < 320 同理 |
| 折叠 | 折叠后固定 36px 竖排条，内容不渲染（不占 DOM）；展开回折叠前宽度 |
| 分隔条 | 5px 视觉、9px 命中区；`cursor: col-resize`；拖动时 `user-select: none` 且不产生文本选择 |
| 双击复位 | 分隔条双击 → 该侧回到默认宽度 |
| 键盘 | 分隔条 `focusable`，`←/→` 每次 ±8px，`Home` 复位 |
| 窄屏 | 视口 < 1180px：右栏默认折叠、左栏 300；< 900px：两栏均折叠为竖排条，画布优先 |
| 状态栏 | 底部常驻单行：pack 数、节点/边数、求值 ms、保存状态、当前选中摘要；右侧不放大段说明 |

### 4.3 右键菜单
| 上下文 | 菜单项 | 禁用/特殊条件 |
| --- | --- | --- |

## 5. 性能指标
| 项 | 指标 |
| --- | --- |
| 基准数据集 | `perf.big.blueprint.json`：200 节点（含 2 个各 500 元素的 list 节点 → 约 2000 端口）、1 个 5MB buffer |
| 平移/缩放 | 平均 ≥ 45fps，p95 帧 ≤ 33ms（M1） |
| 拖动节点 | ≥ 50fps，且拖动期间 `evaluateGraph` 调用次数为 0，`pointerup` 后 1 次 |
| 首屏 | DOMContentLoaded → 可交互 ≤ 1.5s；首次绘制可见节点 ≤ 300ms |
| 求值 | 200 节点 ≤ 300ms；求值期间主线程单次阻塞 ≤ 200ms |
| 内存 | 堆占用 ≤ 300MB（含 5MB buffer 与其 base64 副本） |
| 交互反馈 | 所有指针操作视觉响应 ≤ 150ms；菜单/浮层打开 ≤ 100ms |
| 虚拟化要求 | 节点级视口裁剪必须实现（P0-13）；元素端口不再「只显示前 8 个」，改为按需展开且展开态不创建不可见行的 DOM |
| 降级规则 | 缩放 < 0.5 简化节点内容；< 0.25 连线直线化；可见节点 > 120 时关闭节点阴影/渐变；小地图在节点 > 500 时按 2px 采样。降级不得改变命中区域与选择行为 |

验收方式：新增 `perf.big.blueprint.json` 作为固定基准数据；QA 用 Performance 面板录制 + 状态栏 `ms` 双证据；数值以 3 次录制中位数判定。

## 6. 撤销/重做行为边界
| 类别 | 规则 |
| --- | --- |
| 入栈 | 添加节点、删除节点、移动节点、连线、断线、重连（覆盖旧输入）、参数/端口模式修改、复制粘贴、批量删除、pack 载入、pack 新建/重命名/启用切换/删除、buffer 载入（File 节点换文件）、改基址 —— 即除下表「不入栈」外的全部文档变更 |
| 不入栈 | 视口平移/缩放、选择变化、面板宽度/折叠、分组折叠、元素端口展开、小地图/网格开关、只有 UI 焦点的变化 |
| 合并 | 一次拖动（`pointerdown`→`pointerup`）合并为 1 条，多选拖动也是 1 条；同一输入框连续编辑按 500ms 空闲或失焦合并为 1 条；连续 3 次以上同类「参数微调」不跨字段合并 |
| 栈深 | 上限 100 步（含 undo + redo），超出丢弃最旧；剪贴板内容不随撤销变化 |
| 与保存 | 自动持久化不清空栈；记录「保存点」位置，撤销/重做回到该点时顶栏转为「已保存」，离开保存点即「未保存」 |
| 清空栈 | 打开图（`Ctrl+O`）成功、恢复示例、清空画布——三者清空 undo 与 redo，并在状态栏提示一次「历史已重置」 |
| pack 变更 | pack 删除作为 1 条原子操作，撤销必须同时恢复 pack 源码、其节点、其连线；pack 重命名只改元数据，不触碰节点 id |
| 一致性要求 | 任一步 undo/redo 后 `JSON.stringify({nodes,edges,packs})` 与目标状态深度相等（排序无关）；节点 id 生成器不得回退（避免 id 复用） |

## 7. pack 管理
**数据模型**
```ts
interface PackEntry {
  id: string;        // 稳定 id，首次导入生成，重命名不变
  name: string;      // 显示名，唯一性不强制但重名时 UI 标注序号
  source: string;    // .bp.ts 源码全文
  enabled: boolean;  // 默认 true
  origin: 'builtin' | 'imported' | 'created';
  updatedAt: number; // 用于持久化与冲突判断
}
```

| 项 | 规则 |
| --- | --- |
| 持久化介质 | `localStorage`：`memlink:packs:v1`、`memlink:graph:v1`（图 + 面板布局 + 折叠态）、`memlink:ui:v1`（轻量偏好）；全部带 `version` 字段，不匹配则丢弃并提示 |
| 容量 | 单 pack 源码 ≤ 1MB；pack 数 ≤ 32；单次写入 ≤ 5MB；超限：拒绝操作 + 提示实际值/上限，不写入半成品 |
| 切换语义 | `enabled` 为唯一开关，不做「当前激活 pack」单选——多个 pack 可同时启用，节点库按 pack 分组并列；禁用后：节点库隐藏该组、画布上该 pack 的节点转入「pack 已禁用」错误态（保留位置与连线，可一键清理） |
| 多 pack 节点 | 新节点添加时归属其来源 pack 的 `packId`；跨 pack 复制粘贴保留原 `packId`，若目标 pack 被禁用则落到禁用态并提示 |
| 失败回滚 | 写入前先序列化校验 JSON 可解析；`setItem` 抛错（配额/隐私模式）→ 内存态回滚到写入前快照，状态栏显示「未持久化」，顶栏保存状态保持「未保存」 |
| 启动恢复 | 读取缓存 → 逐个 `loadBlueprintPack(source)` 编译；单个失败不影响其他：该 pack 标记 `error`，其节点渲染为错误态，提示含 pack 名与首行错误 |
| 与打开图兼容 | `memlink-blueprint/1` 结构不变，`packs[]` 的 `{id,name,source}` 继续写入，额外允许可选 `enabled`（旧文件缺省视为 true）；打开图时同 id pack 以图中为准并提示「已同步 N 个 pack」；图中引用了未知 pack 的节点保留为错误节点，不静默删除 |
| 删除保护 | 删除 pack 前列出受影响节点/连线数量；勾选「同时删除节点」才连带删除，否则节点转错误态 |

- **删除死代码**：`legacy` 字段无任何消费方，整体移除。
- **易用性**：空画布引导升级为完整操作提示（添加/跟随地址/查找/布局/快捷键）；hex 跳转框非法输入红框 + title 说明。
- 回归基准：`cdp-verify.mjs` 62 项；单元测试 258 项。

### 第七轮追加需求（配置自动继承）

- 再次添加同类内置节点时，宽度 / 符号 / 字节序 / 指针宽度等下拉自动沿用上一次的设置；只继承与默认值不同的项，显式修改优先。

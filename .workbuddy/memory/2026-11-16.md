# 2026-11-16

## mem-link 商业化优化方向调研

- 产出 `docs/optimization-research.md`（约 300 行）：参照 ComfyUI / ImHex / Nybble 与 2026 商用基线（IDA 9.5、Binary Ninja 6.0、Ghidra 12.2、Volatility 3 / MemProcFS / Volcano），给出定位、六大优化方向、目标架构、三阶段路线图、定价与 UI 方向。
- 核心结论：定位在「地址空间 + 未知结构」象限（线性偏移工具与反编译器之间的空位）；商用第一道墙是信任模型（pack 是代码 + 蓝图内嵌源码 + `new Function`，打开别人的图即执行其代码），第二道是求值性能（主线程全量重算），第三道是交付物（无 CLI / 报告 / diff / 断言）。
- 关键建议：缓存键改祖先链签名；抽 `AddressSpace`（段表 + 页表）替代 `idxToAddr` 式 pack 函数；把 4096 静默截断改为可见截断；环检测升级为环可视化；补语义级 diff（同一蓝图换 buffer）；蓝图内嵌进导出报告；AI 只提案不改图，用覆盖率 / 校验和做否证。
- 路线图：A（0–3 月）稳定性 + CLI + 报告；B（3–9 月）WASM/mmap + 多数据源 + 表达力 + diff；C（9–18 月）注册表 + App Mode + MCP/AI + 企业能力。
- 定价空档判断：$99–249 个人永久 / $499–899 商用席 / 企业按年；单文件 HTML 保留为 Community 与内网卖点，桌面壳为 Pro。

## 元素解析收紧（同日修正）

- 只在类型可推断时提供「元素解析」：来源端口本身是元素，或该地址已有**唯一**已知类型；推断不出来、或同地址出现多种类型（`KnownType.ambiguous`）时不出现该项，不再用首个类型硬猜。
- 移除浮层里的手动类型下拉和检查器里的 PACK / 类型选择；`packId` / `typeId` 只由跟随推断写入，避免强制指定导致字段全错。
- 空元素节点不再铺模板字段：`portsFor` 对无 `inst` 的元素返回空 `outputs`，`address` 端口也只在绑定类型时暴露；空节点不进问题列表。节点标签统一为「元素解析」。
- 验证：293 单测通过；`cdp-verify.mjs` 74/74；`cdp-verify-follow.mjs` 19/19（新增「类型不可推断时不出现元素解析」「空元素节点 0 字段」两项）。

# blueprint-evaluation Specification

## Purpose
定义蓝图求值器对外可观察的行为：每个端口值属于哪一类、数据源如何被解析、截断如何被报告、问题如何被表达。它是画布、检查器、问题面板与后续 CLI 的共同契约。
## Requirements
### Requirement: 值类别必须显式可判别

求值器产出的每个端口值 MUST 携带显式类别。元素/记录类值 MUST 使用 pack 代码无法伪造的标识；未声明类别的对象 MUST 按 JSON 值处理，MUST NOT 按元素解码。计算节点的返回值 MUST 先经过规范化再发布。

#### Scenario: 计算节点返回伪元素

- **GIVEN** 一个计算节点返回普通对象 `{ addr, typeName, fields }`
- **WHEN** 下游把它接到 `number` 输入
- **THEN** 该值按 JSON 处理，节点产生原因码为 `INVALID_VALUE` 的告警，且不按 `addr` 解码

#### Scenario: 真实元素仍可当地址使用

- **GIVEN** 链表节点的 `elem:0` 输出
- **WHEN** 把它接到 `number` 输入
- **THEN** 使用该元素地址，行为与当前版本一致

### Requirement: 数据源解析不得触发上游求值

节点确定数据源时 MUST 只依赖图结构、节点参数与资产表，MUST NOT 为解析数据源而求值上游节点。例外是数据源由上游的字符串、字节输出或有来源的字节范围显式提供：这些连接 MUST 按值依赖参与环检测。字符串与普通字节输出作为数据源时 MUST 以基址 0 生效。字节范围 MUST 保留所属资产、映射和原始绝对范围，MUST NOT 归零、复制出另一份资产或允许下游越过范围读取；失效的范围 MUST NOT 回退到全量转储或其他数据源。

#### Scenario: 值依赖与来源依赖不互相判环

- **GIVEN** 解析节点 A 的缓冲区来自 File，B 的数据源线来自 A 的 `buffer` 输出，且 A 的某个字段输入来自 B 的输出
- **WHEN** 求值整张图
- **THEN** 不产生 `CYCLE`，A 与 B 都得到各自的结果

#### Scenario: 字符串仍可直接作为内存镜像

- **GIVEN** 文本常量的文本输出接到节点 B 的数据源口
- **WHEN** 求值 B
- **THEN** B 以基址 0 解析这段文本，且该依赖被登记为值依赖而非来源依赖

#### Scenario: 有来源的字节范围限制下游读取

- **GIVEN** 一个以 `0x1000` 为基址的转储，以及取其 `0x1020` 开始 8 字节的范围作为下游的数据源
- **WHEN** 下游在 `0x1020` 读取 4 字节，再在 `0x1026` 读取 4 字节
- **THEN** 第一次读到原转储对应内容，保持资产身份；第二次报告范围越界，不回退到全量转储

#### Scenario: 读取结果反过来确定其输入范围

- **GIVEN** A 使用 B 的字节范围作为数据源，B 的长度又来自 A 的读取结果
- **WHEN** 求值整张图
- **THEN** 产生可定位的 `CYCLE` 问题，而不是忽略该依赖并读取全量转储

### Requirement: 截断必须区分自然结束与因上限停止

求值器 MUST 区分"数量恰好等于上限且遍历自然结束"与"因达到上限而停止"。后者 MUST 报告上限、停止位置与是否可继续，MUST NOT 与自然结束共用同一个截断标记。

#### Scenario: 恰好达到上限但链在此结束

- **GIVEN** 链表上限为 256，链恰好有 256 项且第 256 项的 `next` 为空
- **WHEN** 求值该链表
- **THEN** 结果为 256 项且 `truncated = false`

#### Scenario: 因上限被截断

- **GIVEN** 链表上限为 256，链仍有后续项
- **WHEN** 求值该链表
- **THEN** 结果为 256 项，`truncated = true`，并给出 `limit`、`at` 与 `canContinue = true`

### Requirement: 问题条目必须结构化

每条问题 MUST 暴露稳定原因码、严重度、定位信息（节点，可选端口与地址）与人类可读消息；可选修复动作 MUST 以可执行描述给出。原因码 MUST NOT 只存在于展示字符串中。

#### Scenario: 按原因码聚合

- **GIVEN** 图中有三条 `NO_SOURCE` 问题
- **WHEN** 用户打开问题面板并按原因码过滤
- **THEN** 三条同时显示，且过滤不依赖解析展示文案

#### Scenario: 从问题定位到字节

- **GIVEN** 一条带地址的 `OUT_OF_BOUNDS` 问题
- **WHEN** 用户点击该问题
- **THEN** 对应节点被选中，并高亮该地址所在字节

### Requirement: 结构引用必须解析到唯一来源

求值器 MUST 按稳定身份解析每个结构引用：文档布局、某个 pack 的某个类型，或由布局派生的 pack 类型。解析结果 MUST NOT 依赖 pack 的加载顺序、显示名或“第一个同名类型”。引用缺失、pack 被禁用、来源与类型不匹配、嵌套引用成环或布局引用成环时，节点 MUST 产生带稳定原因码的可定位问题，并停止该节点的结构读取；MUST NOT 输出空记录、全零字段或改读另一个来源。

#### Scenario: 禁用被引用的 pack

- **GIVEN** 一个读取节点引用了 pack `p1` 的 `Header`
- **WHEN** 禁用 `p1` 后求值
- **THEN** 该节点报告结构来源不可用并指出 `p1`，不读取其他 pack 的同名 `Header`

#### Scenario: 循环嵌套结构

- **GIVEN** 布局 A 包含 B，B 又包含 A
- **WHEN** 求值引用 A 的节点
- **THEN** 报告循环引用，节点不递归解码，其他分支仍可求值

### Requirement: 同一结构的跨入口解码结果一致

同一个结构通过 pack 节点或无脚本读取节点进入时，求值器 MUST 使用相同的字段偏移、结构长度、字节序、嵌套与位域规则，并产出相等的字段值。pack 来源的字段转换 MUST 在无脚本读取中执行同一条转换路径；布局来源没有转换时 MUST 输出原始值。结构名、结构长度、字段地址定位 MUST 指向同一份字节，MUST NOT 因入口不同而改变值的类别或精度。

#### Scenario: 两条入口读取同一地址

- **GIVEN** 同一份转储、同一个 pack 类型和相同起始地址
- **WHEN** 分别通过 `structNode` 和“读结构”读取
- **THEN** 所有字段的原始值、转换值、偏移、长度和地址一致

#### Scenario: 位域跨入口一致

- **GIVEN** 一个包含共享存储单元位域的布局及其导出的 pack 类型
- **WHEN** 两条入口读取同一段字节
- **THEN** 每个具名位段的数值相等，字节序变化时两侧同步变化

### Requirement: 枚举映射与联合视图不改变值

枚举 `values` MUST 只影响显示文案，MUST NOT 改变原始值、端口值、字段宽度或下游计算；下游收到的仍是整数。联合布局的多个字段 MUST 各自从同一段字节解码，MUST NOT 因共享偏移而合并、清空或只保留一个值。位域、枚举和联合组合时，每个具名字段 MUST 保留自己的值类别。

#### Scenario: 枚举下游仍得到整数

- **GIVEN** 布局字段 `state` 的 `values` 把 1 映射为 `Run`
- **WHEN** 把该字段接到数值比较或断言
- **THEN** 下游收到整数 1，而不是字符串 `Run`

#### Scenario: 联合字段各自解码

- **GIVEN** 一个 `union: true` 布局在偏移 0 有 `u32 asU32` 与 `f32 asF32`
- **WHEN** 求值该布局
- **THEN** 两个字段都从偏移 0 读取并保留各自的值，不出现一个字段覆盖另一个字段

### Requirement: 嵌套结构读取受明确边界约束

嵌套 `record`/`array` 解码 MUST 在进入前校验目标结构长度、数组数量、元素大小与读取范围，并受与现有集合读取一致的深度、数量和字节预算约束。达到预算或越界时 MUST 保留已成功读取的前缀并报告停止原因，MUST NOT 把未读取的元素伪装成零值或空记录。

#### Scenario: 嵌套数组超出转储

- **GIVEN** 一个布局声明 8 个元素，但转储在只剩 3 个元素的位置开始
- **WHEN** 求值该结构
- **THEN** 得到前 3 个有效元素并报告越界位置，不补齐 5 个零元素

#### Scenario: 嵌套过深达到预算

- **GIVEN** 结构层级超过求值器允许的嵌套预算
- **WHEN** 求值该结构
- **THEN** 报告深度预算与停止位置，已读取的外层字段仍可用

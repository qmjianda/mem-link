# desktop-interactions Specification

## Purpose
让本地转储工作台符合桌面与 Web 应用的操作预期：常用动作能直接找到，同一动作在点击和键盘上结果一致，文件与草稿的状态可信，用户随时能取消或回到原来的工作。
## Requirements
### Requirement: 文件入口明确区分新建、打开、导入和示例

工作台 MUST 提供可直接操作的「新建蓝图」「打开蓝图」「导入转储」「导出蓝图」和「查看示例」。没有可恢复的草稿时 MUST 打开空白工作区，并提供导入转储或查看示例的入口。「导入转储」MUST 向当前工作图加入来源而不替换蓝图；「新建蓝图」MUST 不带入上一张图的 pack、布局、节点或连线。新建或打开有效蓝图若会替换当前非空工作图，MUST 先说明影响并提供取消；打开失败或取消 MUST 保留原图。

#### Scenario: 首次从自己的转储开始

- **GIVEN** 浏览器中没有可恢复的草稿
- **WHEN** 用户启动并导入自己的转储
- **THEN** 空白图中只添加并选中该转储，不混入示例的节点、布局或数据源

#### Scenario: 查看示例不动工作图

- **GIVEN** 当前工作图有配置、选中项和可撤销操作
- **WHEN** 用户查看并编辑一个示例，随后点击「返回我的蓝图」
- **THEN** 当前工作图的内容、选中项、视口和撤销状态恢复原样；示例的编辑和自动缓存均没有替换工作草稿

#### Scenario: 取消替换保留工作

- **GIVEN** 非空工作图此前只做过浏览器自动缓存
- **WHEN** 用户打开另一张有效蓝图或新建蓝图，在替换确认中取消
- **THEN** 当前图及其草稿保持不变；自动缓存成功不是静默覆盖的许可

### Requirement: 保存状态区分浏览器草稿和导出文件

状态区 MUST 明确区分草稿待缓存、完整缓存、仅缓存结构而需要重载的转储，以及缓存失败；失败或裁剪 MUST 有可见、持续的反馈和恢复入口，不能只靠限时通知。导出 MUST 生成当前版本的蓝图，包含当前实际可用的转储字节；已缺失的转储 MUST 在导出前明确告知。点击导出与应用接收到的 `Ctrl/Cmd+S` MUST 触发同一动作，自动缓存 MUST NOT 触发下载。浏览器不能确认文件落盘时，应用 MUST NOT 声称文件已保存成功。

#### Scenario: 转储超过草稿缓存预算

- **GIVEN** 当前图含有超过浏览器草稿预算的转储
- **WHEN** 自动缓存仅保存了结构和来源元数据
- **THEN** 顶栏持续显示转储需重载，可查看受影响的来源并导出仍在内存中的完整图

#### Scenario: 撤销分支不是旧保存点

- **GIVEN** 已缓存一版蓝图，随后撤销到较早状态
- **WHEN** 在撤销后继续编辑，生成新分支
- **THEN** 不因为新旧历史游标相同就显示新分支已缓存，实际缓存成功后才更新状态

### Requirement: 导入结果明确且 HEX 解析不篡改字节

粘贴 HEX 与载入 HEX 文件 MUST 使用同一套解析规则。常用的空白分隔字节、连续偶数位 HEX、带 `0x` 的两位字节和 `hexdump -C` MUST 正确读取；地址与 ASCII 栏不得当作数据。含有孤立半字节、意外文本、跳跃或倒退地址的输入 MUST 在提交前指出位置，不得悄悄截断、补齐或替换现有数据。不能不经确认展开的 `*` 压缩行 MUST 明确拒绝并提示重新导出未压缩的内容。

同一批拖入的可识别文件 MUST 各有处理结果。只有转储和 pack 时，MUST 导入该批所有可处理项；如果有一份蓝图，MUST 先按打开蓝图的规则确认目标，确认成功后才处理同批其他项。包含多份蓝图而无法确定目标时 MUST 明确说明并要求分开打开，取消或校验失败时不把其余文件误导入当前图。

#### Scenario: 标准 HEX 转储尾部地址不是数据

- **GIVEN** 输入两行 `00000000  01 02 03 04  |....|` 与 `00000004`
- **WHEN** 用户粘贴并提交
- **THEN** 只载入 `01 02 03 04` 四字节；若改为不完整的 `01 02 3`，提示出错位置并保留原转储

#### Scenario: 同批导入转储和 pack

- **GIVEN** 一份 `.bin` 和一份 `.bp.ts`
- **WHEN** 同时拖入工作区
- **THEN** 两项都得到处理并显示各自结果，不会因为识别出 pack 就无提示地跳过转储

### Requirement: 试读与创建节点是独立动作

选中字节后，检查器 MUST 立即显示当前来源、地址、试读类型与字节序、试读值或字节不足的原因。键盘通过地址跳转选中的字节 MUST 提供同样的试读。更换试读设置 MUST NOT 修改蓝图、增加节点或产生撤销记录。用户明确选择「添加读数值节点」时 MUST 使用相同的来源、精确地址、类型与字节序，一次提交创建节点及所需连线；试读无效时不得添加看似有效的节点。

#### Scenario: 把一次试读保存成解析

- **GIVEN** 用户在非零基址的转储中选中可读取的字节
- **WHEN** 把试读改为大端 `u16`，查看结果后点击「添加读数值节点」
- **THEN** 试读阶段图未变化；创建的节点值与预览一致，指向同一来源和地址，一次撤销移除本次节点及连线

### Requirement: 跟随地址可选择来源并优先展示可用操作

在字节、节点或端口附近 MUST 有可点击的「在此地址解析」或「添加解析节点」入口。跟随窗口 MUST 显示实用的来源名称和地址，优先提供与当前来源兼容的读取操作，高级偏移链默认折叠。候选存在多个可用映射时 MUST 让用户按名称和基址明确选择，不选第一份；对于已经绑定来源的地址和受限字节范围，MUST NOT 悄悄换文件或扩大范围。偏移和下标继续遵循现有类型约束，不隐式当作绝对地址。

#### Scenario: 两份转储映射到同一地址

- **GIVEN** 两个不同的转储均覆盖 `0x1000`，来源没有确定
- **WHEN** 用户执行「在此地址解析」
- **THEN** 可辨认并选择两份来源；取消不会添加节点，确认后新节点只读取所选来源

### Requirement: 对话框遵循焦点与键盘约定

快速添加、图内查找、跟随地址、结构浏览及工作区确认等模态对话框 MUST 有可访问的名称和可见关闭或取消控件。打开时焦点 MUST 进入对话框，Tab 和 Shift+Tab 不得进入背景；关闭时 MUST 回到触发控件或下一步合理位置。Escape 只关闭当前最上层窗口。方向键在候选列表中移动当前项并使其可见；搜索框中的 Enter 使用当前候选，其他控件上的 Enter 保持该控件的原生语义。输入法组合期间的 Enter、方向键和 Escape MUST NOT 误触发应用命令。

#### Scenario: 焦点与实际执行一致

- **GIVEN** 已打开「快速添加」，且焦点已落到第二个候选按钮
- **WHEN** 用户按 Enter
- **THEN** 只添加第二个候选，焦点移至新节点或其检查器，而不是添加第一项

#### Scenario: 取消嵌套跟随窗口

- **GIVEN** 用户在结构浏览中打开跟随地址
- **WHEN** 按 Escape
- **THEN** 只关闭跟随窗口，回到原来的结构项，不关闭结构浏览或改变图

### Requirement: 主流程不依赖拖动或隐藏手势

导入转储、添加节点、选择输入/输出并连线、选择来源、定位或添加解析节点 MUST 有可见的点击及键盘路径。保持拖动和双击作为快捷方式；不能连接时必须用文字说明原因，不只修改颜色。连接到已占用输入 MUST 让用户能识别将替换哪条线，连接和替换均能一次撤销；Escape 取消未提交的连接。

#### Scenario: 不用拖线完成连线

- **GIVEN** 有两个可连接的端口
- **WHEN** 用户依次点击或用键盘选中两端
- **THEN** 完成同样的连线并收到状态反馈，无须按住并拖动；不兼容或取消时原有连接保持不变

### Requirement: 全屏设计器遵循页面导航与焦点约定

结构设计器 MUST 作为页面级视图打开：打开时焦点 MUST 进入设计器标题或第一个可操作项，背景蓝图 MUST inert 且不可通过 Tab 或屏幕阅读器访问；关闭时焦点 MUST 回到触发控件或读结构节点。URL hash MUST 反映当前布局栈，浏览器后退/前进 MUST 在嵌套布局和蓝图之间导航。Escape MUST 按「取消手势 → 关闭浮层 → 返回父布局 → 退出设计器」的顺序只处理最上层。所有拖动或画布操作 MUST 有可见的点击或键盘路径；输入法组合期间的 Enter、方向键和 Escape MUST NOT 触发应用命令。

#### Scenario: 打开与关闭焦点

- **GIVEN** 用户从检查器的「打开结构设计器」进入
- **WHEN** 设计器打开，随后按「完成」关闭
- **THEN** 打开时焦点进入设计器且背景不可 Tab 进入；关闭后焦点回到原按钮，原节点仍被选中

#### Scenario: 浏览器返回嵌套布局

- **GIVEN** 用户从 `Header` 进入 `Entry`
- **WHEN** 用户按浏览器后退
- **THEN** 只回到 `Header`，不离开当前蓝图；再后退才回到蓝图

#### Scenario: Escape 只关最上层

- **GIVEN** 设计器中打开了一个模板浮层
- **WHEN** 用户按 Escape
- **THEN** 只关闭模板浮层；再次按 Escape 才返回父布局或退出设计器

#### Scenario: 无拖动也能创建

- **GIVEN** 用户只使用键盘
- **WHEN** 用户打开「插入字段」菜单并选择类型和偏移
- **THEN** 创建结果与拖拽创建一致，并收到成功或失败的文字反馈

#### Scenario: 输入法组合不触发命令

- **GIVEN** 用户正在设计器的文本输入中使用输入法
- **WHEN** 用户按 Enter、方向键或 Escape
- **THEN** 输入法优先处理，不触发提交、移动或退出

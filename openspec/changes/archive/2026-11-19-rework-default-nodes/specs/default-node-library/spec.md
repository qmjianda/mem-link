## Purpose

定义面向本地二进制与内存转储的默认节点库。用户可用职责单一、可诊断的操作，把读取、地址定位、记录展开和验证串起来，不为探索一份新转储先写脚本。

## ADDED Requirements

### Requirement: 默认新增入口只提供适用的通用操作

节点库、快速添加和「在此地址解析」 MUST 从同一套可发现性规则筛选候选。「在此地址解析」只展示能消费当前地址的操作及已启用的适用 pack 节点。默认节点按数据源、读取、定位、集合、校验组织，不将 NVMe PRP 等协议专用逻辑列为通用操作。系统 MUST 移除「新建 pack」，保留导入 `.bp.ts` 及已有的启用、禁用、重命名、删除功能。随应用发布的示例 MUST 能用当前节点定义求值；旧图及旧缓存不在迁移范围。

#### Scenario: 空白图不用创建 pack

- **GIVEN** 一张不包含 pack 的空白图
- **WHEN** 用户打开节点库、快速添加或从合法地址发起解析
- **THEN** 不会出现「新建 pack」或通用 PRP 候选，用户可开始使用通用节点，仍可主动导入 `.bp.ts`

#### Scenario: 打开随应用发布的 NVMe 示例

- **GIVEN** 默认 NVMe 示例的 PRP 展开节点属于其 pack
- **WHEN** 用户加载示例并求值
- **THEN** 得到相同的页地址与有效的数据页解析结果；不依赖内置 PRP 定义

### Requirement: 显示形式不改变解析值

检查器 MUST 提供适用的进制、时间、枚举名称、标志位和字节预览，且改变显示方式 MUST NOT 改变输出值或创建节点。需要参与下游计算的位段 MUST 可作为布局中有名称和宽度的字段输出。仅供临时查看的跳转、解读和集合浏览 MUST NOT 改变图；当用户选择把操作保存为解析逻辑时才创建节点。

#### Scenario: 预览标志后接出具名位段

- **GIVEN** 一个记录的状态字段按位显示
- **WHEN** 用户切换显示格式，再将布局中定义的某个位段连接到断言
- **THEN** 显示格式不改变数值；断言使用该位段的数值，而不是预览文字

### Requirement: 地址换算维持类型、精度和来源

新解析工作流 MUST 区分映射地址、字节偏移、元素下标和普通数值；接线不得隐式重解释地址或把已声明的偏移当下标。普通整数仅在显式声明用途或绑定到明确语义的换算输入后参与寻址。换算地址 MUST 只做计算：以有来源的基准加字节偏移，或加下标与字节步长的积，不读取内存；拒绝无效步长、下标或结果超出可表示地址范围。整数和地址 MUST 支持无损 64 位值，包括输入、连线、展示、导航及基址的保存和恢复。若上下文无法唯一确定来源，MUST 提示选择来源而非自动选第一份转储。

#### Scenario: 同地址的两份 dump 不混读

- **GIVEN** 两份字节不同的转储映射到同一个非零基址
- **WHEN** 用户从第二份转储的基准加偏移得到地址并连到读取节点
- **THEN** 读取第二份转储；若下游明确指定了冲突的来源，则提示冲突而不是使用另一份

#### Scenario: 64 位地址和数值保留最低位

- **GIVEN** 转储基址为 `0xFFFF800000000001`，其中存有 `u64` 值 `0xFEDCBA9876543211`
- **WHEN** 用户保存并重开图，再从基址读取该字段并跟随基址定位
- **THEN** 读取值、跟随地址、连线回显都保持精确，且定位到原始第一个字节

### Requirement: 基础读取各自定义读取边界和失败条件

载入转储 MUST 提供只读映射、基址及长度。字节范围 MUST 保留来源和绝对起点。读数值 MUST 按指定宽度、类型和字节序输出单个数值；读字符串 MUST 按指定编码读取定长字节数或在明确上限内寻找终止符。定长读取不足、终止符缺失、编码错误及超限 MUST 区分报告，MUST NOT 静默取较短的内容作为成功。读指针 MUST 只读取和解释一个指针，不解析目标记录；空指针、读取失败、目标未映射 MUST 能区分，读出的未映射指针 MUST 保留真实值供排查，MUST NOT 以 `0` 代替失败输出。新节点 MUST NOT 为同一数值生成仅用于展示的十六进制或二进制副本端口。

#### Scenario: 终止符缺失不是空字符串

- **GIVEN** 从转储末尾尝试读取一段 UTF-8 的零终止字符串，范围内没有零字节
- **WHEN** 用户运行读取
- **THEN** 报告未找到终止符，并标明读取范围；结果不作为成功的文本供下游使用

#### Scenario: 区分空指针、失败和未映射地址

- **GIVEN** 有一个值为零的指针、一个超出转储的非零指针、一个只有 2 字节可读的 8 字节指针位置
- **WHEN** 分别用「读指针」求值
- **THEN** 分别显示「空指针」「目标未映射」「读取失败」；未映射项显示真实地址，失败项不会沿连线输出假零

### Requirement: 固定结构布局可在蓝图中定义并复用

用户 MUST 可在界面定义具名布局与字段名、字节偏移、类型和必要的宽度、字节序，不依赖 `.bp.ts` 或执行自定义代码。布局 MUST 随图保存、可由多个节点引用，并在字段改名时保留有效连线。读结构 MUST 从指定起点按布局读取一条记录，输出具名、可接线的字段；检查器 MUST 能定位字段对应的原始字节。无效布局、字段越过声明边界、字段无法读取 MUST 有明确诊断。

#### Scenario: 修改共享布局后保存重开

- **GIVEN** 一张无 pack 的图中两个读取节点引用同一个布局，`count` 字段已接线
- **WHEN** 用户修改字段显示名，保存并重开
- **THEN** 两节点仍引用该布局，原有连线仍绑定同一个字段，点击字段能定位原字节

### Requirement: 集合操作输出可取项值并报告停止原因

展开数组 MUST 按起点、类型、项数与字节步长读取，返回有类型的集合。遍历链表 MUST 按记录布局和 `next` 字段读取，支持绝对地址和池下标、可配置结束值与最大项数。集合的每项 MUST 保留源地址及字节位置，按下标取项 MUST 接受可绑定的下标。遍历 MUST 区分自然结束、环、字节不可用或越界、达到上限，保留已成功读取的前缀并暴露停止位置；没有读到的项不能变成零或空记录。

#### Scenario: 表头控制数组起点和项数

- **GIVEN** 用户用无脚本布局读到 `tableOffset` 和 `count`，并将转换后的表地址和 `count` 接入数组
- **WHEN** 用户打开集合或用下标读取第二项
- **THEN** 按声明的步长读取对应记录，能取到其字段，并能定位到转储中该项的原始字节

#### Scenario: 池下标链表的结束状态可区分

- **GIVEN** 链表以 `base + index × stride` 定位，`-1` 代表终止，`0` 是合法下标
- **WHEN** 分别读取自然结束、成环、指向转储外及仍有后续但达到上限的四份数据
- **THEN** 共用同一布局和推进规则并返回相应状态，已读取的项仍可检查；在恰好达到上限且下一项为 `-1` 时显示自然结束

### Requirement: 校验和与断言分开

算校验和 MUST 只用选定算法对完整字节范围产出实际值，不能接受隐式截断数据作为成功。断言 MUST 将实际值与预期值或边界比较；区分通过、不通过和因输入缺失、无效类型或上游失败而未能校验。不通过和未能校验 MUST 可定位到节点及可获得的来源字段或字节范围；断言 MUST NOT 改写转储或阻止独立分支求值。

#### Scenario: 区分内容不匹配和读取失败

- **GIVEN** 一条断言将计算出的校验和与表头中的预期值比较
- **WHEN** 依次使用匹配的转储、内容不同但可完整读取的转储、以及截断的转储
- **THEN** 分别得到通过、不通过和未能校验；两类异常可以定位到相应的范围或字段

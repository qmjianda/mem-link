## Why

当前无脚本结构只能在 318px 检查器里逐字段填表。写一个 16 字节结构要滚动、记偏移、反复展开，自动排布、锚定、嵌套、位域和重叠关系都不可见；用户是在“填表”，不是在“设计结构”。字段越多，误操作和返工越明显。

底层已经有稳定的 `BinaryLayout`、`compileLayout`、`StructureRegistry` 和统一端口身份，不需要改文档格式。现在缺的是一层真正可用的可视化编辑工作区：把空间关系直接画出来，让拖动、缩放、对齐、嵌套和位域编辑有明确的几何反馈，同时保留键盘、撤销、校验和引用影响这些成熟编辑器的基本约束。

## What Changes

- 新增全屏「结构设计器」页面，从读结构节点的检查器摘要进入；保留原蓝图的选择、视口和撤销状态，关闭后回到原位置。页面有独立 URL（`#design/<layoutId>`），浏览器前进/后退与嵌套布局面包屑一致。
- 检查器降级为「结构选择 + 摘要 + 打开设计器」；字段偏移、类型、位域等编辑不再在右栏重复出现。链表的 `next` 字段选择仍留在检查器。
- **字节视图**：行/字节标尺、字段块、自动/锚定状态、嵌套记录、定长数组、联合叠层；支持从类型面板拖拽创建、拖动字段、拖右边缘改长度、拖动重排手柄调整自动顺序、空白格插入、缩放/平移/适应。
- **位视图**：按存储单元分组，显示位标尺和位域条；支持拖动位域、拖左右边缘改位宽、修改存储单元、添加/删除位域、位序显示切换（只影响显示）。
- **直接操作语义**：拖动自动字段会明确锚定到具体偏移；拖动重排手柄只改声明顺序；拖动过程只做预览，松手时校验并提交；非法落点回弹并说明原因；一次手势只产生一次可撤销编辑。
- **选择与精确编辑**：单主选中 + 多选批量删除/复制；右栏只编辑当前选中项；底部字段表承担精确输入、错误定位和键盘导航；状态栏显示长度、已用/空闲、重叠和字段数。
- **商业级交互**：完整键盘路径、焦点恢复、输入法安全、空状态、错误状态、删除引用警告、会话级“撤销本次打开后的全部修改”、上下文菜单、复制/粘贴/重复、性能预算和可访问性。
- 不修改 `memlink-blueprint/3` 文档格式，不迁移已有布局；pack 类型仍只读。设计器只编辑文档布局，不复用 pack 编辑路径，也不引入任意节点连线。
- **位域语义收紧**：同一存储单元内的位域区间重叠从“未校验”变为硬错误；已有重叠的布局原样加载但显示错误，不自动改写，用户可以逐步修复。

## Capabilities

### New Capabilities

- `structure-designer`: 全屏结构设计器的信息架构、字节/位视图、选择模型、直接操作、诊断、键盘与商业级交互契约。

### Modified Capabilities

- `layout-authoring`: 可视手势与字段表编辑必须产生同一份布局；自动字段拖动锚定、重排只改顺序、非法手势不写入文档、一次手势一次撤销。
- `default-node-library`: 读结构检查器改为结构选择、摘要、`next` 字段和设计器入口；字段几何编辑迁到独立设计器，关闭后保持节点选择与图视口。
- `desktop-interactions`: 全屏设计器作为页面级编辑视图，补齐深链/浏览器返回、焦点恢复、背景 inert、Escape 分层、无拖动路径和输入法约定。

## Impact

- **新增编辑层**：`src/bp/designer/`（页面壳、字节画布、位域泳道、属性面板、字段表、几何/分析/操作纯函数）；`BlueprintApp` 负责挂载、路由、会话检查点和全局撤销。
- **替换右栏编辑**：`src/bp/Inspector.tsx`、`src/bp/LayoutEditor.tsx` 改为结构摘要与入口；`styles.css` 增加设计器样式；不改 `BinaryLayout`、`doc.ts`、`persist.ts` 或求值器。
- **测试与文档**：新增几何/操作/分析单测、集成测试和真实浏览器回归；补充 `docs/` 与 README 的设计器快捷键和操作说明。
- **不改格式**：无文档迁移、无兼容分支；现有布局和示例直接进入设计器。位域重叠的旧布局会显示可修复错误，不静默解码，也不自动改写文件。
- **风险**：拖动与自动排布的语义容易含混，必须用重排手柄 + 锚定预览固定下来；128 字段和嵌套布局的拖拽性能需要在预览层做局部更新；全屏页面与现有单页状态需要明确的路由/焦点边界。
